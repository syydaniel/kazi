# 第五步之二：配乐

做法：代码写谱，用好音源渲成引导音频，再让本机 ACE-Step（xl-sft，cover-nofsq）逐段"演奏"成真乐器。谱定结构和对拍，ACE 定音色。不拿任何现成曲子当引导或样板。

脚本都在 `music/tools/`。`TV` 指 `~/Movies/NAIWA_BEYOND/tools_venv/audio/bin/python`，`ACEPY` 指 `~/ACE-Step-1.5/.venv/bin/python`。都用 `-I -B` 跑。

## 一、前提

- 时间线定稿：`film/src/data/timeline.json`、`film/src/data/env.json`、`vo/paced/narration.wav`。score.json 里存了时间线的 sha，拼接时对不上会报错。
- 时间线变了怎么办，见第七节：整段只是平移的，沿用原来的谱、引导音频和 ACE 候选，只给真正变了的段重新写谱、重新生成。
- 暗场段落以画面为准：SCENES 里带 `dark: 1` 的节。第五版是 ai、thoughts，连同它们前面的章节过场 ch2、ch6。
- 章节过场"落定"那一帧 = ChapterSting 的 a + 0.38 秒。a 每一章不一样，要去 scenes 里查：第五版第二章 a = gap.start + 0.16（钻进小卡屏幕），第三章 a = gap.start − 0.05，其余 a = gap.start。写在 `compose_v5.py` 的 `LAND5`。

## 三、参数

- 速度：每段在 72~78 BPM 里以 0.01 为步长搜，4/4，D 大调。只许三种对拍手段：每段自己的速度、弱起、在最后一小节前插一个 2/4。
- 命中容差：音乐起音减画面帧在 -45 ms 到 +17 ms 之间。A 类（过场落定）落不到就在这一点把段切开；B 类（章节卡、H1）落在窗口里就行；谱上落不到拍上的，拼接时叠一个采样钢琴单音。
- 每段最长 120 秒，超了在章节卡处切。
- ACE：`acestep-v15-xl-sft`，`cover-nofsq`，PyTorch 那条路（`"mlx_dit": false`），64 步，guidance 7，shift 3，`audio_cover_strength` 1.0，`cover_noise_strength` 0.45（6 个都不过门槛时用 0.6 再跑 6 个），reference_audio 用本世界的样板；每段 6 个候选 = 3 个进程 × batch 2，种子 = 基数 + 10 × 段序号 + 0..5（第四版基数 8000，第五版新段 9000）；终版 128 步、同一种子、batch 1。`ACESTEP_GENERATION_TIMEOUT=3600`。
- 引导音频：每段前后各 1 小节余量，不到 10.5 秒把后余量加长；渲完统一到 -18 LUFS。

## 四、筛选门槛（screen.py 的 GATES）

| 门槛 | 阈值 |
|---|---|
| 人声 | CLAP 人声分（三条人声描述的最高余弦减 "instrumental music"）最大窗口 <= max(样板值, 本段引导谱的值) + 0.03；前两名分离人声轨，整体和任一 1 秒窗口都 <= 混音 -20 LU |
| 竖琴、琶音 | 1~4 kHz 快衰减、音高单向的起音串（引导谱同一位置没有的）= 0；CLAP harp 分 <= max(样板值, 引导谱的值) + 0.03 |
| 调 | 全段判为 D 大调或 B 小调；8 秒窗口里 >= 90% 和引导谱色度相关 >= 0.6 |
| 对拍 | 引导谱起音在候选里 50 ms 内找到 >= 80%；漂移 <= 20 ms（起音少于 10 个时不算漂移） |
| 低频 | 150 Hz 以下左右相关 >= min(0.5, 引导谱正文的值 − 0.1) |
| 削波 | 真峰值 <= 0 dBTP，粗略咔哒检测 0 处 |

排名权重：色度一致度 0.25，旋律命中 0.20，说话处安静 0.20，和样板的音色余弦 0.15，响度弧线 0.10，宽度 0.05，高频 0.05。只评正文，余量不评。

样板门槛：人声轨整体和任一 1 秒 <= 混音 -20 LU；guitar 轨 <= -15 LU；drums 轨 <= -20 LU；CLAP 人声 <= 0.02、harp <= 0.05；全段 D 大调（或 B 小调），8 秒窗口 >= 70% 是 D 大调或 B 小调。

## 五、坑

- 本机 ACE 默认用 MLX 跑 DiT，MLX 那条路从纯噪声起步，`cover_noise_strength` 不起作用（`acestep/models/mlx/dit_generate.py` 里 `xt = noise`）。jobs 里写 `"mlx_dit": false` 走 PyTorch，才会把引导谱按 1 - cns 重新加噪再采样。终版要和候选用同一个后端，种子才对得上。
- MLX 64 步、batch 2：100 秒的段一个进程约 16 分钟（和配音任务同时跑时）。
- 路径里有空格（Application Support）：队列文件一行一个路径，按行读，别按空白切。
- ACE 会往引导谱的静音里填东西（A/B 那段第一小节本来是空的，候选里出现了拍点）。所以只评正文，对齐也只用正文里的起音。
- 对齐用"引导谱起音逐个找最近的谱通量峰、取中位数"，两边用同一个检测器。整段起音包络互相关会被余量里多出来的东西带偏，A/B 上偏了 200 ms。
- 谱通量的峰比真实起音晚约 10.7 ms（在引导音频上用谱面时间标定），核对命中点时要减掉。
- 分离（BS-Roformer-SW）在 CPU 上 40 秒要 1~5 分钟；候选多时只分每段前两名，用 `SEP_DEVICE=mps`。
- 分离出来某一轨是数字静音时，响度会是 -120，按"通过"处理。
- 引导音频钢琴本身就比伴奏响很多：按世界整体先压到"中位比伴奏高 4 dB"，再按段微调（最多 ±3 dB）。
- A/B 那条：旁白对齐全片响度以后，个别峰值会超过 0 dBTP，只在峰上做前视下压（最多约 1.4 dB），不整体降。
- 纸到暗、暗到纸的接缝两侧响度差很大（过桥那一小节本来就薄），这是设计如此；同一世界的接缝差要在 1.5 LU 以内。
- 停乐处要切掉混响尾巴，静默里应该是数字静音。
- 门槛要拿引导谱校准。第一轮按"样板值 + 0.03"和"低频相关 >= 0.5"卡，纸面段几乎全军覆没：弦乐和低音提琴的采样本身低频就宽，引导谱正文的低频相关只有 0.24~0.44，候选反而更高（0.33~0.51）；暗场的合成铺底在 CLAP 那里本身就有 +0.01 左右的人声分，引导谱里一个人声都没有。这两种都是量具的偏差，按引导谱校准以后再卡。用 cns 0.6 重跑解决不了这个问题（M04、M05 各用 0.6 重跑了 6 个，同样卡在这两条上）。
- 终版和 64 步版对齐时，两边都要用 `onset_near`。只在终版一边用，会多出 −10.7 毫秒（`onset_near` 自带的固定偏差修正），拼进片子就晚 10.7 毫秒。
- PyTorch 那条路的速度：64 步、batch 2，每秒音乐约 2.5~2.8 秒（M04、M05 实测）；128 步终版每秒音乐约 3.2 秒（M13，45.5 秒的窗口跑了 147 秒）。

## 七、时间线改了以后（第五版的做法）

1. 先把旧的谱、`guide/guide.json`、`cues.json` 备份到 `score/v4/`、`guide/v4/`，被新段顶掉名字的引导音频也备份。
2. 按段对一遍：段里每个字是不是原样平移（`compose_v5.py` 打印的"平移核对"，字数相同、起点差 <= 5 毫秒）；段两头的画面落点（章节过场落定帧、章节卡窗口）是不是跟着平移。字原样平移但画面落点变了的，按画面落点定平移量（第五版 M03：旁白挪 −32.11，画面落定挪 −31.948，按 −31.948）。
3. 平移段：音符、小节线、命中点全部加平移量；`guide.json` 里只改 a、b、content。引导音频本身不能重渲：它的余量里有邻段的音，邻段一换，余量就变了，和已经生成的 ACE 候选对不上。
4. 新段接平移段的地方，新段的尾巴要和平移段引导音频余量里的东西一致（交叉那一拍两边同时响）：纸到暗的过桥音放在余量里那个过桥音的同一时刻（`bridge_t`）；暗到纸、纸到纸的和弦用 `end_chords` 对上（第五版 skill 段收在 G、D5，和 M04 余量里的 G/D、D5 不打架）。新段的 content_end 必须等于下一段的 content_start（打印的"接缝"全是 0 ms）；平移段前面要接新段的入口时，用 `bpm_fix` 把新段速度定成原来那一段的速度（第五版 M10 = 77.8，和原来的 M09 一样）。
5. 旧段的 ACE 日志、jobs、`.done` 挪到 `ace/logs/v4old/`、`ace/jobs/v4old/`，队列里删掉对应的行，新段才不会被当成已经跑完。
6. 筛选缓存带着"时间表 sha + 引导窗口"，平移以后自动重算（说话处安静这一项和时间表有关）。
