# 第五步：声音

声音分三轨：旁白、配乐、音效。旁白永远第一，另外两轨给它让位。

## 配乐

- 本机生成（ACE-Step 1.5），不用到处找授权。具体做法见本文后面的"配乐生成"一节。
- **让位比好听更要紧**：旁白说到关键的地方，音乐往后退；句子之间的空当，音乐再浮上来。
  - 说话时音乐比旁白低 12 到 18 LU（`mix.py` 默认 15），空当里低 6 LU。
  - 按逐字时间做：句子开始前 0.2 秒压下去；两句之间不到 1.2 秒就别浮上来，来回起伏会很吵。
  - 说话时再把音乐的 1 到 4 kHz 压低 2 到 3 dB，人声最要紧的清晰度在这一段。
- **停乐**：全片停 2 到 4 次，留给最重要的几句（结论、反转、揭晓）。突然安静本身就是重音。
- 段落转换用和声过渡、单个乐器过桥，或者干脆在章节卡上停住；少用淡出淡入糊过去。
- 一段音乐同时活跃的声部最多三层；长铺底加一直不停的固定音型，听久了很累。

## 音效

音效从画面的打点表里导出，画面在哪一帧动，声音就在哪一帧响：

```bash
cd film && npm run cues          # 写出 out/cues.json
```

分四层，每层的质感跟着画面走：

| 层 | 什么时候 | 例子 | 音量 |
|---|---|---|---|
| 落点 | 关键词上的动作到位 | 纸面：铅笔点、印章；暗场：柔和的电子点 | 最响的一层，但比旁白低 10 dB 以上 |
| 过渡 | 镜头移动、换场 | 空气声、纸张滑动；峰值放在动得最快的那一帧 | 中 |
| 拟音 | 小人和物体的小动作 | 脚步、翻页、笔尖划过 | 轻 |
| 氛围 | 整段铺底 | 房间底噪、暗场的低频嗡声 | 很轻，几乎听不出来，停了才发现 |

- 每个音效都要有淡入淡出（至少 5 毫秒），不能有咔哒声。
- 同一种音效有几个版本轮流用，连续两次一模一样，耳朵会听出来。
- 说话时音效再低 3 dB。
- 宁少勿多：不是每个动作都要有声音，关键词上的那一下最重要。

### 打点太多时先筛一遍

画面里每个动作都打点很方便，可全放出来会吵。这条片子导出了 861 个点，平均每分钟 58 个，听起来像一直在敲东西。混音前先筛：

```bash
python tools/thin_cues.py film/out/cues.json film/out/cues_thin.json      # 默认每分钟 22 个左右
```

它按优先级挑：重击和叮（关键词、结论）先留，其次是镜头大移动的嗖，再其次是弹出，最后才是点击、翻纸、滴答这些。同一时刻只留最重要的那一个；每种声音有自己的最小间隔和每分钟上限（重击每分钟最多 2 个，弹出 8 个）。这条片子筛完剩 346 个，每分钟 23 个上下。混音时 `--cues` 给筛过的那份。

### 音效素材

`--sfx-dir` 下按种类放 wav。素材库的许可一般**不允许再分发音效文件本身**，所以素材包只放在自己电脑上，不进仓库、不进网盘。做这条片子时是这样准备的：让 AI 从本机的音效库里按种类挑文件，去掉开头的静音，滤掉不要的频段，按起音切成一个个小片段，再做几个升降调的变体，按种类放进 `pop/`、`whoosh/` 这些文件夹。换成你自己手里的素材，照这个思路让 AI 写一个小脚本就行。

## 混音

```bash
python tools/mix.py --timeline timeline.json --voice vo/narration.wav --music audio/music.wav \
    --cues film/out/cues.json --sfx-dir audio/sfx --out audio/mix.wav --stems audio/stems \
    --video film/out/video.mp4 --final out/final.mp4
```

- `--sfx-dir` 下按 kind 建子文件夹放 wav（`pop/`、`tick/`、`whoosh/`……）。没有的 kind 用内置合成音效兜底，只适合先听效果。
- 片子里要原样播放的声音（比如对照测试的配音、A/B 试听）写在 `src/beats.ts` 的 `CLIPS` 里，`npm run cues` 会一起导出 `out/clips.json`，混音时加 `--clips film/out/clips.json --clip-root film/public`。片段的响度自动对齐旁白，放的时候音乐也让位。
- 成片 -14 LUFS，真峰值不超过 -1 dBTP，48 kHz。`--stems` 会另存三轨，方便进剪辑软件再调。
